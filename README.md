# PlanarSpace 🌌

## Overview
PlanarSpace is a sophisticated generative art engine and spatial simulation that explores the intersection of trigonometry, noise-based motion, and perspective projection. Built using raw HTML5 Canvas and JavaScript, it simulates an environment where particles trace complex, collapsing orbital paths within a 3D coordinate system, projected dynamically onto a 2D plane. 

The project demonstrates a deep understanding of mathematical modeling, including parametric functions, Simplex noise for organic movement, and custom perspective division to simulate depth and light attenuation.

## Features
- **3D to 2D Perspective Projection**: Implements a custom rendering pipeline that calculates screen coordinates and object scaling based on a virtual viewer distance and Z-axis depth.
- **Organic Motion Profiles**: Utilizes Simplex noise algorithms to generate non-linear, fluid vertical oscillations for every object in the simulation.
- **Dynamic Orbital Physics**: Objects follow pre-computed parametric paths that collapse toward a central focal point, simulating a gravity-like pull or spatial decay.
- **Optimized Rendering**: Employs an off-screen buffer (`depthCanvas`) to pre-render the environment background, significantly reducing the per-frame computational load.
- **Responsive Resolution Scaling**: A robust resize handler that maintains a consistent aspect ratio while scaling internal canvas resolution for high-DPI displays.
- **Depth-Based Light Attenuation**: Automatically calculates HSL lightness values relative to an object's Z-position to enhance the perception of three-dimensional space.

## Usage
To experience the simulation, PlanarSpace requires a local development server because it utilizes JavaScript ES Modules.

1.  **Clone the Repository**: Download the project files to your local machine.
2.  **Launch a Local Server**: Use an extension like "Live Server" in VS Code or run `python -m http.server` in the project directory.
3.  **Interact**: Open your browser to the local host address. The simulation automatically scales to your window size.
4.  **Visual Mechanics**: 
    - Circles are instantiated at the periphery with randomized HSL values.
    - Each circle calculates its entire flight path upon creation to ensure smooth high-frame-rate performance.
    - Objects are sorted by depth every frame to ensure correct visual stacking (painter's algorithm).
